# 09 · 圈三块，变成三页 PPT

**观众要记住：** 自己决定分页和页序，把一张画布交付成演示稿。

**成片目标：** 20 秒；做方案汇报的人。

**状态：** 脚本草案；已核对文档/源码，尚未实录验收。

## 开拍准备

专用画板预先准备三个不重叠区域：问题背景、方案架构、推进计划；标题醒目，各区不超过 5 个要点，避免跨区连线。

## 可直接使用的提示词 / 输入

> 准备画板时使用：在当前画板创建三个独立汇报区域，依次是“问题背景”“方案架构”“推进计划”。主题为订单异常处理改进：问题是异常分支不清晰；方案是区分支付失败、库存不足；推进计划是流程评审、实现、验证。每区一个标题，不超过五个要点，使用可编辑元素，区域之间留白，不编造数据。

## 分镜与操作

| 成片时间 | 实际操作与镜头 | 屏幕字幕 |
| --- | --- | --- |
| 0–3 秒 | 展示包含三个区域的总画布。 | 一张画布，准备好三页内容。 |
| 3–9 秒 | 进入“批量框选”，依次圈出问题、方案、计划；展示实际编号或选区顺序。 | 按顺序圈选。 |
| 9–12 秒 | 点击“完成”，选择“导出 PPT”并执行。 | 每个区域，成为一页。 |
| 12–17 秒 | 打开本次文件，展示三页缩略图并依次切页。 | 页序，由你决定。 |
| 17–20 秒 | 选中第二页中的节点，展示可编辑状态。 | 三页内容，一份可编辑 PPT。 |

## 成片验收

本次导出只有三页，顺序与框选一致，内容没有跨页裁切；支持的对象可编辑。

## 拍摄边界

不是按 AI 回复文本自动分页；批量 PNG 等其他格式是独立文件，不是多页文档。

src/components/BatchExportDialog.tsx；docs/CANVAS_AND_EXPORT.md：多个区域 → 多页 PPT
