# 02 · 圈住这里，让 AI 接着改

**观众要记住：** 不用重述整张图，把选区作为上下文继续修改。

**成片目标：** 18 秒；已有图、需要反复改方案的人。

**状态：** 脚本草案；已核对文档/源码，尚未实录验收。

## 开拍准备

在专用画板准备“用户 → Agent Loop → 输出”的简洁结构；不超过 6 个主节点；提前保存修改前快照。

## 可直接使用的提示词 / 输入

> 把引用区域中的 Agent Loop 展开成 Model、Tool、Context 三个可编辑节点，保留外部输入和输出关系。只调整这部分需要的布局，其余内容保持原样。

## 分镜与操作

| 成片时间 | 实际操作与镜头 | 屏幕字幕 |
| --- | --- | --- |
| 0–3 秒 | 展示完整架构图，鼠标停在 Agent Loop 上。 | 这里，还需要展开。 |
| 3–7 秒 | 使用“框选导出”圈住该区域，点击“添加到对话”；展示输入区的区域引用。 | 圈起来，加入对话。 |
| 7–10 秒 | 输入提示词并发送。 | 把 Agent Loop 展开成三部分。 |
| 10–15 秒 | 剪短等待，展示 Model / Tool / Context 的实际修改结果。 | AI 根据选区继续修改。 |
| 15–18 秒 | 拉回全图，让观众同时看到内部变化与外部关系。 | 在原图上，继续完善。 |

## 成片验收

引用必须清晰出现；修改后的三个节点与外部连线正确；比较修改前后全图。

## 拍摄边界

选区是上下文，不是严格的编辑隔离。若区域外被错误修改，修正或重录；宣传字幕不承诺“绝不影响其他区域”。
