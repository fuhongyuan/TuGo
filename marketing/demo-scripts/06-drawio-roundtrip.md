# 06 · 已有 draw.io 图，也能接着用

**观众要记住：** 导入、修改，再导出到兼容工具继续编辑。

**成片目标：** 20 秒；需要在绘图工具之间交接的人。

**状态：** 脚本草案；已核对文档/源码，尚未实录验收。

## 开拍准备

准备自制、仅含基础矩形、文字、连线的 draw.io XML；录制前验证 TuGo 导入及目标编辑器再次打开导出文件；目标编辑器名称与版本写入录制记录。

## 可直接使用的提示词 / 输入

> 无需 AI 提示词。使用已验证的基础 draw.io XML 样例。

## 分镜与操作

| 成片时间 | 实际操作与镜头 | 屏幕字幕 |
| --- | --- | --- |
| 0–4 秒 | 打开“DSL 与画布”，选择 draw.io XML，粘贴 XML 并展示预览。 | 已有的图，带进来。 |
| 4–8 秒 | 确认导入，在画布上修改一个节点名称。 | 继续改方案。 |
| 8–13 秒 | 框选内容，在导出面板选择 draw.io 并实际保存。 | 再导出交接。 |
| 13–20 秒 | 在兼容编辑器打开刚导出的文件，选中并移动一个节点。 | 交付后，也能接着编辑。 |

## 成片验收

目标编辑器打开的是本次导出文件；标签修改保留；节点与连线可以继续编辑。

## 拍摄边界

只展示验证过的基础对象；不承诺所有 draw.io 样式与对象无损往返。目标编辑器未验证前，本条不进入发布素材。
