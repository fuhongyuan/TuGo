# 03 · 指着图，讨论图

**观众要记住：** 用画布中的具体区域作为问题背景。

**成片目标：** 16 秒；评审流程、解释方案的人。

**状态：** 脚本草案；已核对文档/源码，尚未实录验收。

## 开拍准备

准备订单流程，包含库存不足到退款的分支；聊天区留足空间展示简短回答。

## 可直接使用的提示词 / 输入

> 解释引用区域中的库存不足分支：它从哪里触发，最后到哪里？用不超过三条短句回答，指出图上是否画出了“退款失败”处理，不修改画布。

## 分镜与操作

| 成片时间 | 实际操作与镜头 | 屏幕字幕 |
| --- | --- | --- |
| 0–3 秒 | 展示订单图，框选库存检查与退款分支。 | 这个分支，意味着什么？ |
| 3–6 秒 | 点击“添加到对话”，展示区域引用。 | 直接把图交给对话。 |
| 6–9 秒 | 发送提示词，保留问题可读的停顿。 | 解释这部分，检查遗漏。 |
| 9–16 秒 | 展示实际简短回答，与选区同时入镜。 | 看着图，把问题聊清楚。 |

## 成片验收

回答确实引用选区中的节点与关系，正确指出是否存在退款失败路径；录制前后画布一致。

## 拍摄边界

不把模型分析包装成经过专业认证的结论；若模型答非所问，应改进提示词后重新录制真实运行。
