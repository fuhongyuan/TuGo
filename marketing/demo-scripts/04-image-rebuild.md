# 04 · 把流程图截图，变成能改的图

**观众要记住：** 已有图片可以成为重画可编辑结构的参考。

**成片目标：** 20 秒；手上只有旧图截图的人。

**状态：** 脚本草案；已核对文档/源码，尚未实录验收。

## 开拍准备

准备自制、清晰的订单流程 PNG：下单 → 支付 → 发货，支付失败 → 重试支付，共 4 个节点；使用已验证支持视觉输入的模型。参考图可放画布左侧用于对照，还必须作为聊天附件上传。

## 可直接使用的提示词 / 输入

> 参考附件流程图，在画布右侧重画为可编辑节点和连线。保留节点文字、主要方向和成功/失败分支，不要把原图片当作最终结果。无法辨认的文字标为“待确认”，不要猜测。

## 分镜与操作

| 成片时间 | 实际操作与镜头 | 屏幕字幕 |
| --- | --- | --- |
| 0–3 秒 | 展示原图，停留在可识别的结构。 | 只有截图，也能接着改。 |
| 3–7 秒 | 点击聊天附件按钮，选择 PNG；展示附件缩略图并发送提示词。 | 上传图片，让 AI 参考重画。 |
| 7–12 秒 | 剪短等待，展示原图与新图并排。 | 重画成节点和连线。 |
| 12–17 秒 | 拖动新图的“发货”节点，再修改标签。 | 生成后，继续编辑。 |
| 17–20 秒 | 并排展示原图和完成的新图。 | 从截图，到可编辑画布。 |

## 成片验收

新图节点、文字、分支方向与原图逐项核对；必须拍到独立节点可编辑。

## 拍摄边界

不是像素级复刻承诺，也不是直接把图片转换成原生对象。图片放入画布不等于模型已经收到附件。
