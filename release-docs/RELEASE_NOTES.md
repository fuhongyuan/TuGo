# TuGo 1.0.0 · 图狗

首个公开版本。TuGo 是本地优先的 AI 无限画布：手动画图，与画板对话，将圈选区域转换为图片、PDF 或可编辑 PPT。

## 本版内容

- TuGo / 图狗品牌、Logo 和默认绘画游标。
- 形状、文字、图片、连线、分组与无限画布。
- 项目、文件夹、多会话、自动保存与版本快照。
- 内置 TypeScript Agent Runtime、自备模型、Skills、外部 MCP。
- Mermaid 和 PlantUML/draw.io 兼容子集导入。
- 图片、SVG、PDF、PPTX、draw.io 导出与多区域 PPT。
- 主题/语言偏好及部分本地化。
- 中英文文档与 Apache-2.0 许可。

## 安装与边界

实际支持系统/架构、附件及签名公证状态以维护者发布时填写的信息为准。没有附件时可从源码启动。自备模型服务可能收费，不附送 API Key 或额度。

[快速上手](../docs/GETTING_STARTED.md) / [Getting started](../docs/en/GETTING_STARTED.md)。

AI/导出结果需检查；翻译不完整，互动教程尚未提供；数据库备份不含附件/凭据，本地加密不是钥匙串。外部模型/MCP 可能接收相关数据。见 [已知限制](KNOWN_LIMITATIONS.md) 和 [隐私说明](../PRIVACY.md)。
