# TuGo v1.1.0：让 AI 画得更稳，让图稿真正可编辑

这个版本围绕 AI 长任务可靠性、画布编辑和开放调用进行了集中改进。

## 值得体验

- **画完之后再检查**：引入分层观察，将执行回执、几何检查和 DOM 渲染证据分别记录，减少“工具成功就当画面完成”的误判。实际像素和外部 Office 显示仍需单独检查。
- **长会话持续工作**：接近上下文预算时自动压缩历史，保留用户约束、当前计划和近期完整工具批次；历史证据可按引用读取。明确超限时进行有界恢复，避免盲目重放已执行操作。
- **更顺手的画布**：改善嵌套图层选择、框内文字和连线文字编辑、容器拖动、跨画板复制粘贴，并修复无效缩放状态。
- **手动画出演示页**：框选多个演示区域，支持移动、缩放、命名、排序和删除；播放时切换区域并自动适配视口，配合激光笔和小地图展示。
- **把 TuGo 交给你的 Agent**：本地 CLI 与独立 Skill 支持画板、文件夹、原生编辑、导入导出和快照。生成结果保存在桌面应用，可继续人工编辑。Harness 需能在同一电脑执行本地命令。
- **更清楚的聊天反馈**：长消息默认折叠，选区引用影响 AI 游标起点；改善执行、取消、错误与交付验证状态展示。

## 背后的技术思路

1. **观察和执行分离**：工具回执说明发生了什么，观察证据说明结果是否满足目标；不同证据范围不互相冒充。
2. **按需注入证据**：按任务和上下文预算选择摘要与细节，降低重复工具结果挤占上下文的成本。
3. **上下文有生命周期**：结合参考 tokenizer 与实际 usage 校正估算，按闭合批次压缩，保留原始历史和账本；这不等于无限上下文。
4. **恢复必须有边界**：取消、迟到回执、陈旧观察和重试分别处理，避免旧任务污染新任务；对未知写入结果先核对状态。
5. **图形仍是结构化对象**：布局、连线、编辑和导出围绕节点与边工作，而不是把结果固化为一张图片。

同时更新 Electron、Mermaid、PDF 与构建依赖，并补充兼容、观察协议和上下文生命周期回归测试。安全审计结果以本次验证记录为准，不代表未来永久无漏洞。

## 下载与升级

- macOS：Apple Silicon DMG；本次构建采用 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。
- Windows：x64 EXE 安装器；支持范围以随版本记录的 Windows 验证结果为准。
- 先退出旧版再安装；沿用 TuGo 应用标识和资料库位置。升级前建议备份完整 profile、附件和原应用，测试不得使用唯一真实数据副本。
- CLI Skill 作为独立附件提供，不含模型密钥、用户数据或本机接口 token。

构建、测试与包校验结果另附发布验证记录；未运行的检查不会标记通过。
