TuGo Mac 安装须知（请先阅读）
===========================

本安装包适用于 Apple Silicon Mac。
本次构建使用 ad-hoc 签名，未使用 Apple Developer ID 签名，也未经过 Apple 公证。
macOS 可能提示“TuGo 已损坏，无法打开，你应该将它移到废纸篓”。
这可能与下载隔离标记和未公证有关，不一定表示文件实际损坏。

安装步骤
--------
1. 退出旧版 TuGo。
2. 将本窗口中的 TuGo.app 拖到 Applications（应用程序）文件夹。
3. 先尝试从“应用程序”打开 TuGo。
4. 如果出现上述提示，确认安装包来自项目的官方 Release 后，打开系统“终端”，
   复制下面一整行命令，按回车执行：

   xattr -dr com.apple.quarantine "/Applications/TuGo.app"

5. 再次从“应用程序”打开 TuGo。

这个命令只移除指定 TuGo.app 的下载隔离属性，不会删除你的画稿和配置。
它不会为应用补上 Apple 公证，也不能修复实际损坏的安装包。
如果你将应用安装到了其它位置，请将命令中的路径改为实际的 TuGo.app 路径。
如果终端提示路径不存在，确认已完成第 2 步，不要直接对 DMG 内的只读应用执行命令。

如果仍然打不开
--------------
从官方 Release 重新下载安装包，核对附带的 SHA-256 校验值。
不要关闭 macOS 的全局安全保护。将具体提示反馈给项目维护者。

官方发布地址：https://github.com/fuhongyuan/TuGo/releases

升级前建议备份完整的用户资料库及附件。覆盖应用本体通常沿用原资料库；
本说明中的命令不访问或修改资料库。
