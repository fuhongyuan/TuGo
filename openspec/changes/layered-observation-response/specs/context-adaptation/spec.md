# Spec Delta

## Purpose

在不同上下文预算和模型能力下提供适合下一轮决策的输入，同时保护原始执行事实、关键约束和未解决问题，避免因为截断、摘要或不支持的输入模态造成虚假判断。

## ADDED Requirements

### Requirement: 模型调用预算治理
系统 SHALL 在模型调用前核算历史、工具定义、附件及输出预留，记录投影决策并保留估算余量；无法容纳最小必要证据时 MUST 有界停止或升级。

#### Scenario: 压缩仍无法容纳
- **WHEN** 紧凑视图仍超过安全预算
- **THEN** 停止或升级并说明原因，不无限压缩或发送非法截断 JSON

### Requirement: 紧凑视图保持决策必要信息
系统 SHALL 在压缩时保留阻断数量、未知项、目标约束、未完成事项及明细引用，并保持工具调用和结果的协议配对；不得为节省上下文静默改变业务语义。

#### Scenario: 大结果精简
- **WHEN** 完整工具结果过大
- **THEN** 返回可取回引用与范围说明，关键问题及完整数量不因摘要被隐藏

### Requirement: 模态适配不伪造能力
系统 SHALL 根据已知模型能力选择输入；不支持或能力未知时明确说明证据局限，未经授权不自动换模型。

#### Scenario: 纯文本模型遇到图片
- **WHEN** 当前模型不支持图片
- **THEN** 使用可用结构化证据或升级，不声称已经查看图片
