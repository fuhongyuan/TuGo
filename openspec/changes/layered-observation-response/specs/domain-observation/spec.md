# Spec Delta

## Purpose

让不同领域在共同观察契约下提供业务检查和环境证据，保留领域策略与宿主能力的边界；让查询降级和画板局部修复透明、受约束且可再次验证。

## ADDED Requirements

### Requirement: 领域检查不绑定通用循环
系统 SHALL 通过注册的领域适配和宿主探针运行检查，同一通用循环支持非绘图查询与 TuGo；无界面宿主缺少 DOM 能力时明确报告不可用。

#### Scenario: 无界面观察
- **WHEN** 无 UI 宿主收到实时画板观察请求
- **THEN** 返回能力限制，不以导出 PNG 冒充实时 DOM 证据

### Requirement: 查询结果范围透明
领域工具 SHALL 明确完整、分页、部分和汇总的范围并提供明细入口；明确要求明细时不得静默仅返回汇总，总数未知不得编造。

#### Scenario: 大量明细
- **WHEN** 查询结果超过单次返回容量且用户要求明细
- **THEN** 返回有限明细、分页入口及范围说明，未取回部分不标为已交付

### Requirement: 修复与观察隔离
只读观察 MUST NOT 写入业务状态。领域自动修复 SHALL 遵守锁定、权限和预算，记录副作用并复检新版本；拒绝候选不得计作已应用。

#### Scenario: 扩高引入碰撞
- **WHEN** 新节点的扩高候选引入新的严重碰撞
- **THEN** 不提交该候选，保留问题并升级

### Requirement: 实际画板证据有明确覆盖
画板探针 SHALL 检测遮线、文字越界、箭头缺失及不可见描边；未稳定、过期或未检查的目标不得通过。DOM、像素和外部 PPT 覆盖 MUST 分开报告。

#### Scenario: 呈现故障注入
- **WHEN** 稳定 DOM 注入上述任一故障
- **THEN** 返回对应对象及问题定位，不因几何数据正常而通过

#### Scenario: 播放与版本竞态
- **WHEN** 观察时发生播放投影、字体未就绪或画板版本改变
- **THEN** 等待有界稳定或报告未知/过期，不沿用旧通过结论
