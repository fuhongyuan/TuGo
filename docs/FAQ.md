# 常见问题

[文档目录](README.md) · [English](en/FAQ.md)

## 开源免费，为什么还需要 API Key？

源码按 Apache-2.0 提供，但第三方模型服务独立计费。TuGo 不附送模型额度；配置和测试模型可能产生实际请求。

## 能完全离线使用吗？

手动画布和本地数据不依赖 TuGo 云服务；远程模型、Web 工具和外部 MCP 可能需要网络。当前不内置离线大模型。

## 画板会发给模型吗？

执行任务时，模型可通过画板工具获取内容；不一定只有你圈选的部分。对话、工具结果和附件也可能进入上下文。圈选不是隐私隔离，请看 [隐私说明](../PRIVACY.md)。

## API Key 保存在哪里？

保存在本地 `runtime-secrets.json` 的加密记录中，数据库通常保存凭据引用。不是系统钥匙串；能访问应用数据且掌握本机上下文的程序可能恢复凭据。不要分享这个文件。

## 浏览器预览为什么不能用 AI？

`npm run dev:web` 只启动 Renderer。请用安装版或 `npm run dev` 启动 Electron，才能使用数据库、文件访问和 Runtime。

## 模型保存成功但无法调用怎么办？

先测试连接，检查 Provider 协议、服务根地址/路径、实际模型 ID、密钥权限、额度和限流。只有模型支持时才开启视觉。报错信息脱敏后再反馈，参考 [配置指南](CONFIGURATION.md)。

## 为什么切换语言后还有中文？

本地化尚未覆盖全部页面。已接入的词条缺失时回退英文，但尚未接入的工具栏、弹窗和部分状态提示可能仍为中文。已有画板文字和聊天记录不会自动翻译。

## 图片导入后能直接变成可编辑 PPT 图形吗？

不能。图片仍是图片。可以让视觉模型参考图片重画为节点/连线，再导出；必须检查识别与重画结果。

## 为什么导入或导出后样式不一样？

Mermaid、PlantUML、draw.io 和 PPTX 都有各自的格式和样式能力，TuGo 实现的是兼容范围而非任意内容的无损往返。导入后检查图结构，导出后检查字体、文字、连线与页序。

## “完整备份”能用于换机吗？

单独的 ZIP 不行：目前只有两个数据库，不含附件和凭据，也没有一键全量导入。请阅读 [备份与恢复](DATA_RECOVERY.md)，不要删掉原数据。

## 支持 Windows / Intel Mac / Linux 吗？

首发目标是 macOS 13+ Apple Silicon；源码有 Windows x64 打包能力，实机验证状态以 Release 为准。尚不承诺 Intel Mac 和 Linux 桌面支持。

## 有没有互动式教程？

目前提供文字指南，互动式首次使用引导还没有实现。

## 如何报告 Bug？

使用 Issue 中的 Bug Report 模板，提供版本、系统与架构、安装来源、复现步骤、预期/实际行为和脱敏错误。安全漏洞不要公开披露，见 [安全策略](../SECURITY.md)。
