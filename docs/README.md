# TuGo 使用文档

[返回首页](../README.md) · [English documentation](en/README.md)

本文档描述 TuGo 1.0.0 源码中的能力。安装包是否已发布、系统验证与签名状态，请以仓库 Releases 说明为准。

## 新用户

建议按这个顺序阅读：

1. [快速上手](GETTING_STARTED.md)：配置模型并画出第一张图。
2. [图片、圈选与 PPT](CANVAS_AND_EXPORT.md)：上传图片、引用区域、单页和多页导出。
3. [案例与提示词](EXAMPLES.md)：复刻图片、生成汇报图和导出 PPT 的可改写提示词。
4. [配置指南](CONFIGURATION.md)：模型、视觉/非视觉差异、MCP、Skills、主题和语言。
5. [备份与恢复](DATA_RECOVERY.md)：避免把数据库备份误当成完整换机备份。
6. [常见问题](FAQ.md)：连接、导入、语言、导出和安装问题。
