# 图片、圈选与 PPT 教程

[文档目录](README.md) · [English](en/CANVAS_AND_EXPORT.md)

## 将图片加入画布

点击画布工具栏的“添加图片”，选择文件；也可以将图片拖到画布。图片导入后作为画板元素，可以移动和缩放。把图片上传到聊天是另一条路径：它是模型附件，不会自动变成画布节点。

要让 AI 看图分析，先确认使用支持视觉的模型。提示示例：

> 参考这张图片中的流程，在旁边重画成可编辑节点和连线，不覆盖原图。无法辨认的内容请标注，不要猜测。

图片中的文字不会仅因导出 PPT 就自动变成可编辑文字。

### 案例：复刻一张流程图图片

适用于旧流程图截图、会议白板照片或竞品架构图。先在“设置 → 模型”确认本轮模型已启用且实际支持视觉；点击聊天框的附件按钮选择原图。仅把图片放进画布不会让 AI 自动看到它。

发送下面这类提示词，并按你的任务替换方括号内容：

> 阅读附件图片，在当前画板中重画为**可编辑的节点和连线**，不要把原图当作最终交付。请保持原图的主要阅读方向和分组；将无法辨认的文字写为“待确认”，不要补造内容。节点用 [中文/英文] 标签，画在 [原图右侧/空白画板]，完成后列出你无法确认的 3 个点。

完成后逐项检查：节点数量、连线方向、分组边界、决策分支和小字。发现不对时，不要只说“优化一下”，而应给出具体修正，例如“把付款失败连到退款，不要连到发货”。确认结构后，可删除原图片或保留它作参考。

没有视觉模型时，先把图片中的标题、节点、关系和层级整理成文字或 Mermaid，再让模型重画；详见 [视觉模型差异](CONFIGURATION.md#视觉模型与非视觉模型)。

## 圈定内容并交给聊天

1. 选择“框选导出”工具。
2. 在画布上拖出目标区域。
3. 弹窗会显示区域尺寸和包含的图形、连线数量。
4. 点击“添加到对话”，检查聊天输入区出现了区域引用。
5. 输入具体要求并发送，例如：
   > 只调整引用区域中的布局。保留节点名称，统一尺寸，让连线尽量不重叠。

引用用于向模型说明范围，不应被当作绝对的编辑权限隔离；修改后检查区域外内容。若结果不理想，可撤销或使用版本快照。

## 单区域导出

重新框选区域，在弹窗中选择：

| 格式 | 适合场景 |
| --- | --- |
| PNG / JPEG / WebP | 分享或插入文档；图片不可逐节点编辑 |
| SVG | 向量图交付，复杂内容仍需检查目标软件兼容性 |
| PDF | 单页文档 |
| PPTX | 在 PowerPoint 中继续编辑支持的图形、文字和连线 |
| draw.io | 在兼容编辑器中继续修改支持的对象 |

按需选择清晰度和透明背景；选项随格式不同而变化。导出不修改原画板。

## 多个区域 → 多页 PPT

1. 选择“批量框选”。
2. 按预计的页序圈出多个区域。
3. 圈错时用“撤销上个”；重新选择可用“清空”。
4. 点击“完成”，选择“导出 PPT”。
5. 打开生成的 PPTX，核对页序、字体、边界和连线。

每个区域是一页。其他批量格式会按区域分别下载，而不是自动合并成多页 PDF。

## 先让 AI 整理，再生成 PPT

可以先圈选并加入聊天，再提出：

> 把这些内容整理成适合三页汇报的布局：背景、方案、结论。每页保留一个重点，使用可编辑图形，不编造业务数据。

待 AI 修改完成后，检查内容，再用批量框选导出三页 PPT。也可以请求 AI 使用可用的导出工具，但是否调用成功取决于模型与运行结果；手动圈选导出是明确可操作的路径。

PPTX 导出不是任意图片的自动矢量化，也不承诺所有画布效果完全一致。敏感内容应在发送给模型前移除。

### 案例：从一张画板导出三页汇报 PPT

目标：把一张混合画板整理成“问题 → 方案 → 推进计划”三页可编辑演示稿。

1. 先让 AI 或人工把内容分为三个视觉上不重叠的区域。可使用提示词：
   > 将当前画板整理为三块汇报内容：问题背景、方案架构、推进计划。每块保留一个标题和不超过五个关键点；不要编造数据。
2. 在每块内容外预留页边距，检查没有跨页连线或浮动标签。
3. 选择“批量框选”，按“问题背景 → 方案架构 → 推进计划”依次拖出三个区域。
4. 点击“完成”并选择“导出 PPT”。每个区域会成为一页，而不是按 AI 文本自动分页。
5. 在 PowerPoint/Keynote 中打开文件，检查页序、字体替代、对象可编辑性和是否有裁切；需要改内容时回到画板修改后重新导出。

如果你只需要一页，使用普通“框选导出 → PPTX”即可。批量操作中的其他格式会逐区域下载独立文件，不会合成多页 PDF。
