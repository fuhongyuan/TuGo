# 快速上手

[文档目录](README.md) · [English](en/GETTING_STARTED.md)

## 1. 启动桌面应用

从仓库 Releases 下载与你的系统、架构相匹配的安装包。macOS DMG 打开后，将 TuGo 拖到 Applications，再从 Applications 启动。ZIP 包先解压。

首发目标是 macOS 13+ Apple Silicon；不要将 ARM64 包用于 Intel Mac。若系统拦截启动，先核对包来源、哈希与 Release 中的签名/公证说明，不要直接关闭系统安全保护。

没有安装包时，在克隆或解压后的源码根目录运行：

```bash
npm ci
npm run dev
```

源码运行需要 Node.js 25.2.1、npm 11.6.2。浏览器预览 `npm run dev:web` 不提供完整 AI 功能。

## 2. 配置模型

1. 点击右上角设置，进入“模型”，选择“新增模型”。
2. 选择 Provider 协议；填写显示名称及服务端实际接受的模型标识。
3. 按服务商说明填写服务地址和 API Key。没有自定义网关时可以使用该适配器的默认地址。
4. 在高级设置中按服务商规格填写上下文和最大输出长度。只有模型实际支持图片输入时才启用“支持视觉”。
5. 点击“测试”，确认成功后保存，并选为默认模型。测试会发起真实请求，可能消耗服务额度。

不要把示例地址当成可用服务，也不要把 API Key 放到截图或 Issue 中。凭据的本地保存边界见 [隐私说明](../PRIVACY.md)。

## 3. 创建第一张图

点击左侧“新建画板”，在右侧聊天框输入：

> 画一个订单处理流程图。包含下单、付款、库存检查、发货；库存不足时退款。使用中文标签，保留清楚的判断分支。

查看 AI 的运行状态与画布变化。完成后可以继续输入：

> 把流程改成从左到右排列，退款分支放在主流程下方，不改变节点含义。

也可以手动选择矩形、便签、文字与连线工具；双击文字编辑，使用撤销/重做调整操作。自动保存不等于永久版本历史，重要节点建议创建版本快照。

## 4. 图片与区域引用

- 工具栏“添加图片”用于将图片放进画布；聊天附件用于将文件提供给模型，两者用途不同。
- 使用“框选导出”圈住画板的一部分，在弹窗中选择“添加到对话”。
- 输入“只优化这个区域，保留区域外内容”，再发送。区域引用明确任务范围，但仍应检查 AI 的实际修改。
- 理解图片内容需要支持视觉的模型。

## 5. 导出第一份 PPT

框选要交付的区域 → 选择 PPTX → 导出。多个区域使用“批量框选”，按顺序圈选，点击“完成”，再选择“导出 PPT”。每个区域对应一页。

支持的图形、文字和连线会转换为可编辑 PowerPoint 对象；图片仍是图片，复杂样式可能不同。导出后检查字体、连线、裁切和页序。

更多操作见 [图片、圈选与 PPT 教程](CANVAS_AND_EXPORT.md)。使用结束前，可在“设置 → 数据与恢复”导出数据库备份，范围见 [备份指南](DATA_RECOVERY.md)。
